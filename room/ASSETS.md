# Wall artwork

The oak artwork embedded in `src/assets/room.glb` was created with the built-in image generation tool from the user's supplied engraving reference, with an RGBA transparent background.

The flag textures were rasterized from public-domain SVGs:

- [United States flag](https://commons.wikimedia.org/wiki/File:Flag_of_the_United_States.svg)
- [Mexican flag](https://commons.wikimedia.org/wiki/File:Flag_of_Mexico.svg)

The original artwork files, generation prompt, and Blender scene remain in the `website_blender` project.

## Odysseus sculpture

[Odysseus Archer](https://doi.org/10.5281/zenodo.10238931) by **kevinwalter**, licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Original model: [Sketchfab](https://sketchfab.com/3d-models/odysseus-archer-648281b994124d2fbd8f28f02dc77b8a).

Adaptations: warm ivory material with the original baked carving detail, smooth normals, and adjusted scale and orientation. This is a digitally sculpted model, not an archaeological scan. Visitor-facing attribution is under Navigation help → Artwork credit.
