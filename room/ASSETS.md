# Wall artwork

The oak artwork embedded in `src/assets/room.glb` was created with the built-in image generation tool from the user's supplied engraving reference, with an RGBA transparent background.

The flag textures were rasterized from public-domain SVGs:

- [United States flag](https://commons.wikimedia.org/wiki/File:Flag_of_the_United_States.svg)
- [Mexican flag](https://commons.wikimedia.org/wiki/File:Flag_of_Mexico.svg)

The original artwork files, generation prompt, and Blender scene remain in the `website_blender` project.
